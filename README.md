# New-Pokedex
Pokédex interativa desenvolvida para demonstrar lógica de programação, manipulação de dados e design Front-End. O projeto possui mais de 1050 Pokémon, com pesquisa dinâmica por nome, número ou tipo, além de exibir informações detalhadas, características e visualização 3D de cada Pokémon.
